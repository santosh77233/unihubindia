# 🎓 UniHub India

**UniHub India** is a student-first platform designed to help learners across India discover the **right colleges, courses, admissions, scholarships, and career opportunities** — all in one place.

Our mission is to simplify the college discovery journey for students by making educational information **accessible, structured, transparent, and easy to explore**.

---

## 🚀 Vision

Choosing the right college in India can be confusing due to scattered information, lack of clarity, and poor accessibility.  
**UniHub India** aims to solve that by building a smart and modern platform where students can:

- Explore colleges across India
- Compare institutions and courses
- Learn about admissions and eligibility
- Discover scholarships and opportunities
- Make more informed academic decisions

---

### Planned Stack

- **Styling:** Tailwind CSS

- **Database:** PostgreSQL / MongoDB (TBD)
